# Economia por cultivo

Un archivo por cultivo, con la misma pregunta en todos: **cuanta plata mueve una hectarea, y por
eso cuanto soporta de cuota.**

## Como leer los precios, porque es donde mas facil se miente

Hay **tres precios distintos** para el mismo kilo y confundirlos infla el analisis:

| | que es | de donde sale |
|---|---|---|
| **En finca** | lo que cobra el productor | **casi nunca se publica**. Es el que importa |
| **Mayorista (Abasto)** | lo que se paga en el Mercado Central de Abasto de Asuncion | [preciosdelagro.com](https://preciosdelagro.com/), diario |
| **Minorista** | gondola | el mas visible y el menos util |

**La brecha es grande**: prensa paraguaya documento que *"del productor al super, el tomate y la
lechuga cuestan 100% mas caro"* ([Valor Agro](https://www.valoragro.com.py/agricultura/del-productor-al-super-el-tomate-y-la-lechuga-cuestan-100-mas-caro/)).

**Regla de esta carpeta**: cuando solo hay precio mayorista, se dice **"mayorista"** y se estima el
de finca **marcandolo como estimacion**. Nunca se presenta un mayorista como si fuera de finca.
