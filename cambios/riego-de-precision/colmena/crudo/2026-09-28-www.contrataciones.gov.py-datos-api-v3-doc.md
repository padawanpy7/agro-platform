 ¿Cómo utilizar esta documentación?

 
 
 1. 
 El primer paso es registrarse como usuario en el Portal de Datos Abiertos de la DNCP aquí. 
 
 
 2. 
 Una vez registrado como usuario en el Portal, el siguiente paso es crear una aplicación. Al
 crear la aplicación el sistema generará las credenciales (customer key y customer secret)
 y el correspondiente request token, necesarios para realizar la autenticación. Cada aplicación
 tiene un límite de 15 minutos.
 
 
 
 3. 
 El servicio /oauth/token es el que realiza la autenticación, se debe pasar como payload del
 cuerpo del POST HTTP el request token. Si la autenticación se realiza con éxito, el
 servicio devolverá un access token.
 
 
 
 4. 
 El access token generado por el servicio de autenticación tiene un tiempo de vida de 15 minutos.
 Una vez transcurrido ese tiempo el access token expirará y deberá volver a autenticarse para
 conseguir uno nuevo.
 
 
 
 5. 
 Para utilizar los servicios se debe pasar como parámetro de la cabecera Authorization HTTP el access token con
 el siguiente formato: [access_token].
 
 
 
 

 Observaciones 

 
 
 a. 
 Los servicios utilizan la clave OAUTH del Servicio de Autenticación. Dejando vacío este
 parámetro solo se permiten 15 llamados
 por minuto para propósitos de testing. Si se quiere usar los servicios en entornos de
 desarrollo y producción se debe utlizar la
 clave OAUTH cuya validez es de 15 minutos.
 
 
 
 b. 
 Los parámetros con un * son requeridos para el servicio​. 
 
 
 c. 
 La sección "Servicios del Open Contracting Data Standard" devuelve la información de
 Contrataciones Públicas del
 Paraguay en el formato definido por el Estándar Open Contracting (OCDS).
 Para más información acerca del estándar ir a
 https://standard.open-contracting.org/latest/en/ 

 Para más información sobre la implementación del estándar ir a https://www.contrataciones.gov.py/datos/open-contracting-info 
 

 
 
 
 d. 
 Para mantener la performance actual el límite de registros devueltos por cada servicio de lista es de 10.000, 
 se recomienda siempre afinar las búsquedas de manera a encontrar en forma rápida los datos esperados. 
 Si se necesita obtener datos en forma masiva se recomienda hacer la descarga de los documentos CSV 
 que cuentan con todos los datos publicados en la sección Explorar Datos desde la pantalla inicial
 de este sitio o desde este link https://www.contrataciones.gov.py/datos/data
